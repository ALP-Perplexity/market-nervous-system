# Vision
Snapshot: 2026-10-29. Project: Market Nervous System (MNS). Owner: Viktor.

## Product
A continuously operating market-intelligence and trading system: observe markets → maintain an evolving world model → investigate changes → freeze forecasts before outcomes → trade or abstain → evaluate → learn.
The visual identity is a living neural graph containing hundreds of connected orbs. The orbs participate in real research, memory retrieval, forecasting and execution traceability; they are not decorative activity.

## Original vision to preserve
- A market “brain” that breathes crypto and prediction-market information.
- Social/news/Reddit/trend research, asset-platform/CMC research, chart and historical-trade analysis.
- Paper/demo experimentation, including learning from events the system did not trade.
- A memory-maintenance worker that filters, deduplicates, organises, tracks contradictions and prepares compact usable context.
- Persistent links between evidence, narratives, forecasts, strategies, experiences and decisions.
- Professional crypto and Polymarket workflows with autonomous investigation and measured improvement.

## Interpretation
Hundreds of orbs do not mean hundreds of always-running LLM conversations. Only some orbs are processes; bounded workers activate the relevant graph neighbourhood.
“Milliseconds” means a target for prepared local lookup and deterministic processing, measured separately from LLM and venue latency.
The human vault is not an order database. Graphify maps code/docs at development time; Graphiti constructs runtime temporal knowledge graphs.

## Success
Every trade can show why now, evidence used, contradictions, strategy version, invalidation, actual fill and subsequent outcome.
Every eligible setup retains a frozen forecast and decision, including abstention.
Memory and extra agents justify themselves through measurable improvements against simpler baselines.

## First demo
Real observation → evidence → graph update → frozen expectation → act/abstain → paper execution if appropriate → scheduled evaluation → experience → inspectable evidence-to-decision path in UI.
