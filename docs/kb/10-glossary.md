# Glossary
Orb: visual object backed by a stored entity/relationship/task/event.
DecisionPacket: compact typed, versioned and expiring intelligence consumed by code.
Context compiler: bounded, source-linked evidence assembler for a particular task/as_of.
Frozen forecast: immutable original prediction; updates create new versions.
Abstention: explicit no-trade decision that preserves/evaluates the associated forecast.
Point-in-time: information and versions actually available at the specified cutoff.
Shadow strategy: live-data evaluation without placing orders.
Promotion gate: measured criteria before replacing a deployed version.
Derived store: rebuildable graph/vector/vault projection, not canonical truth.
Graphify: intended development repo/KB graph tool; exact installation unverified.
Graphiti: runtime temporal graph-construction/retrieval framework.
Obsidian: optional human-readable Markdown view, not an execution database.
FIXTURE: deliberately synthetic or curated test input, clearly identified.
SIMULATED: hypothetical/paper result with explicit assumptions, not actual fills.
